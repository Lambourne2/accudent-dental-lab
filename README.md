# Accudent Dental Lab

[![License: MIT](https://img.shields.io/badge/License-MIT-yellow.svg)](https://opensource.org/licenses/MIT)

Professional dental laboratory website for Accudent Dental Lab, providing high-quality dental restorations with fast turnaround times and excellent customer service.

## Features

- **Modern, Responsive Design**: Looks great on all devices
- **Secure Authentication**: Patient and dentist login/registration
- **Case Submission**: Easy online case submission with file uploads
- **Material Information**: Detailed information about available materials
- **Contact Forms**: Easy way to get in touch with the lab

## Getting Started

### Prerequisites

- Node.js (v14 or higher)
- npm (v6 or higher)

### Installation

1. Clone the repository:
   ```bash
   git clone https://github.com/yourusername/accudent-dental-lab.git
   cd accudent-dental-lab
   ```

2. Install dependencies:
   ```bash
   npm install
   ```

### Running Locally

Start the local development server:

```bash
npm start
```

The site will be available at `http://localhost:8080`

### Testing Links

To check for broken links in the website:

```bash
npm run check-links
```

## Deployment

This project is designed to be deployed to GitHub Pages. Follow these steps:

1. Push your code to a GitHub repository
2. Go to the repository Settings > Pages
3. Select the `main` branch and the `/(root)` folder
4. Click Save
